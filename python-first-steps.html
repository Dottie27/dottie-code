My First Steps Learning Python

September 26, 2026

I started my coding journey by learning HTML and CSS. At first, my goal was to become a front-end developer and focus on building and designing websites. But with today's world of technology and the way AI is transforming the tech landscape, I became interested in learning more. I decided to expand my skills beyond front-end development and start diving into Python. 

print("Hello, World!")

The code above may look simple, but seeing the code run is a pretty exciting feeling when you're just starting out.

What I've Learned So Far

One thing I learned is that Python is considered one of the easier programming languages to learn, which made me feel a little more comfortable getting started. I also learned that programming involves math, and some of the math can involve algebra. The funny part is that, back in school, math was not exactly my friend. I was okay with the basics like addition, subtraction, multiplication, and division, but algebra? Somehow, algebra and I got along just fine. In fact, I was pretty good at it! So maybe all those years of learning algebra are finally going to come in handy. 😄

Right now, I'm learning Python through an app on my iPad, and so far, I'm doing pretty well on the quizzes. I also get to practice writing Python code by typing in the examples they show me and then seeing the output. Seeing the output come out exactly the way it's supposed to is really awesome. There's something exciting about writing the code yourself, running it, and seeing that it actually works. It makes me feel like I'm really starting to understand what I'm learning.

What's Next?

I'm going to keep practicing Python and learning more about programming. My goal is to eventually be comfortable enough with Python to use it in real projects.

This is only the beginning of my coding journey, and I'm excited to see how much I can learn as I continue building projects and documenting my progress here on Dottie Codes.
