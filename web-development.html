Learning how websites are built and styled.

HTML and CSS were some of the first technologies I started learning on my journey toward becoming a full-stack developer. This page documents what I have learned and the things I am continuing to practice.

What I'm Learning

HTML is used to create the structure of a webpage, while CSS is used to style and design that structure. As I continue learning, I'm practicing how to bring the two together to create websites that look good and are easy to use.

Building Dottie Codes has given me a chance to practice these skills on a real project instead of only following tutorials.
