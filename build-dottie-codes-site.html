Building My Dottie Codes Website: The Journey So Far

November 2026 | Dottie Codes

When I first started learning HTML and CSS, I was mainly focused on understanding how websites were put together. I wanted to learn how to create webpages, experiment with designs, and eventually build something of my own.

At some point, I had the idea of creating a website where I could share my coding journey, talk about what I was learning, and showcase the projects I was working on.

That's when the idea for Dottie Codes began!

What started as a learning project has turned into something I've really enjoyed creating. It's been exciting to watch my ideas come to life and see how much the website has grown along the way.

Where It All Started

I wanted Dottie Codes to be more than just a basic website. I wanted it to have its own look and personality while giving me a place to share my progress as I learn to code.

I started by working on the basic structure using HTML. Then I began adding CSS to bring everything together.

As I worked on the website, I started thinking about the colors, layout, navigation, images, and how I wanted visitors to move from one page to another.

I decided to go with a dark background and add pink and purple accents. I wanted something that felt creative, stood out, and reflected my personality.

I also wanted different sections for my blog posts, Python learning, HTML and CSS, projects, and an About Me page.

Having Fun With the Design

One of my favorite parts of creating Dottie Codes has been designing the website.

I enjoy experimenting with different colors, fonts, layouts, and little details to see how they change the overall look.

Sometimes I'll make a small CSS change and realize it makes the page look completely different. Other times, I'll try something and decide I liked the original design better!

I've spent time adjusting the blog cards, working on the navigation bar, adding images, changing spacing, and making sure the pages have a consistent appearance.

It's been fun being able to take an idea in my head and actually build it into something I can see on the screen.

Learning Along the Way

Building this website has helped me become more comfortable with HTML and CSS.

I've learned how to:

  • Create and organize different website pages.
  • Use CSS to customize colors, layouts, fonts, and spacing.
  • Add images and create blog cards.
  • Make navigation links work between pages.
  • Use GitHub to upload my work and publish my website using GitHub Pages.

Seeing Dottie Codes online for the first time was exciting because it meant that something I had been working on locally was now available for other people to visit!

Of course, I've also had moments where things didn't work the way I expected. Sometimes a page wouldn't display correctly, a change wouldn't appear online, or I would have to go back through my code to find what needed fixing.

But I've learned that troubleshooting is part of the process. Every time I figure something out, I understand a little more than I did before.

Watching Dottie Codes Grow

As the website started coming together, I began adding more content and thinking about what else I wanted visitors to see.

I wanted to share blog posts about my learning experience, write about the things I'm discovering, and eventually showcase more of the projects I'm building.

I also like the idea of having a place where I can look back and see how far I've come.

Dottie Codes isn't just about showing finished work. It's also about sharing the process, including the things I'm still learning and figuring out.

What's Next?

I'm still working on improving Dottie Codes and finding new ways to make it better.

I want to continue adding blog posts, sharing my Python journey, showcasing projects, and improving the overall design and functionality of the website.

As I learn more about web development, I'm looking forward to applying those skills to Dottie Codes and seeing how much further I can take it.

There are still plenty of things I want to try, and I'm excited to keep experimenting.

Final Thoughts

Creating Dottie Codes has been such a fun and rewarding experience.

I started with an idea and a desire to practice what I was learning. Now I have my own website where I can share my journey, showcase my work, and continue growing as a developer.

I've learned that building a website takes patience, creativity, and a willingness to keep trying when something doesn't work the first time.

I'm proud of what I've created so far, and I know this is only the beginning.

Here's to continuing to learn, build, and create something new!
