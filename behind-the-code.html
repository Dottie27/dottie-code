Connecting Python to HTML: Getting Started with Flask

November 2026 | Dottie Codes

When I first started learning Python, I understood that Python could be used to build applications, but I wasn't quite sure how it connected to HTML. I was already familiar with creating HTML pages and styling them with CSS, so learning how to bring Python into the picture was a new experience.

As I started working on my MyStep Journey app, I began learning how Python and HTML can work together using a framework called Flask.

In this post, I'm sharing what I've learned about connecting Python to HTML, setting up Flask, and organizing project files into folders.

1. Understanding How Python and HTML Work Together

Before connecting Python to HTML, it's helpful to understand what each language does.

  • HTML: Creates the structure and content of a webpage.
  • CSS: Controls the appearance, colors, spacing, and layout.
  • JavaScript: Adds interactive features to a webpage.
  • Python: Handles backend tasks, processes information, and communicates with databases.
  • Flask: A Python framework that helps connect the backend to your website.

Think of HTML as what visitors see on the screen and Python as the part working behind the scenes. Flask helps these two parts communicate.

2. Installing Flask

To get started, you need Python installed on your computer. I used Visual Studio Code (VS Code) to work on my project.

First, open your project folder in VS Code and open the terminal.

Create a virtual environment by entering:

python -m venv .venv

A virtual environment keeps your project's Python packages separate from other projects.

Next, activate the environment in Windows PowerShell: 

.venv\Scripts\Activate.ps1

If PowerShell blocks the command, you may need to allow scripts for the current terminal session: 

Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned

Then activate the environment again.

Once your virtual environment is active, install Flask:

pip install flask

Now Flask is installed and ready to use in your project.

3. Organizing Your Project Into Folders

One of the things I learned is that organizing files makes a project much easier to manage.

Instead of keeping every HTML, CSS, JavaScript, and Python file in one folder, Flask uses a structure that separates the different parts of your application.

Here is an example of how a Flask project can be organized:

MyStep Journey/
│
├── app.py
│
├── templates/
│   ├── index.html
│   ├── goals.html
│   ├── history.html
│   ├── profile.html
│   └── edit-profile.html
│
├── static/
│   ├── css/
│   │   └── style.css
│   │
│   ├── js/
│   │   └── script.js
│   │
│   └── images/
│       └── logo.png
│
└── .venv/

What Each Folder Does

app.py: This is the main Python file. It contains the Flask application and the routes that determine which HTML page should be displayed.

templates/: This folder holds your HTML files. Flask looks inside this folder when you use render_template().

static/: This folder holds files that support your website, such as CSS, JavaScript, and images.

css/: This folder holds your stylesheets.

js/: This folder holds your JavaScript files.

images/: This folder holds your website images, icons, and other graphics.

You don't have to create every folder at once. You can add more as your project grows.

4. Creating Your First Flask Connection

Now that the folders are organized, it's time to connect Python to HTML.

Open your app.py file and add: 

from flask import Flask, render_template

app = Flask(__name__)

@app.route("/")
def home():
    return render_template("index.html")

if __name__ == "__main__":
    app.run(debug=True)

Breaking Down the Code

  • from flask import Flask, render_template imports the tools needed to create the application and display HTML pages.
  • app = Flask(__name__) creates your Flask application.
  • @app.route("/") tells Flask which URL should display the home page.
  • def home(): creates a Python function that runs when someone visits that route.
  • render_template("index.html") tells Flask to display the HTML file inside the templates folder.
  • app.run(debug=True) starts the development server and helps identify errors while you're working.

This is the beginning of connecting your frontend to your Python backend.

5. Connecting Your Other HTML Pages

Once the home page is connected, you can create additional routes for the other pages in your application.

For example:

@app.route("/goals")
def goals():
    return render_template("goals.html")


@app.route("/history")
def history():
    return render_template("history.html")


@app.route("/profile")
def profile():
    return render_template("profile.html")

Each route connects a URL to an HTML page.

You can then visit:

  • http://127.0.0.1:5000/ for the home page
  • http://127.0.0.1:5000/goals for the goals page
  • http://127.0.0.1:5000/history for the history page
  • http://127.0.0.1:5000/profile for the profile page

6. Connecting Your CSS and JavaScript Files

After moving your CSS and JavaScript files into the static folder, you need to update the paths in your HTML.

For example, if your CSS file is inside static/css/, use:

<link
  rel="stylesheet"
  href="{{ url_for('static', filename='css/style.css') }}"
/>

For JavaScript inside static/js/, use: 

<script src="{{ url_for('static', filename='js/script.js') }}"></script>

The url_for() function helps Flask generate the correct path to your static files.

You can use the same approach for images:

<img
  src="{{ url_for('static', filename='images/logo.png') }}"
  alt="My app logo"
/>
Remember: Flask uses these paths because your files are stored inside the static folder.

7. Starting Your Flask Application

Once everything is connected, it's time to run your application.

Open the VS Code terminal and make sure you're inside your project folder.

Activate your virtual environment if it isn't already active:

.venv\Scripts\Activate.ps1

Then run:

python app.py

If everything is working, Flask will display a local development address in the terminal.

Open that address in your browser:

http://127.0.0.1:5000/

You can make changes to your HTML, CSS, and Python files and refresh the browser to see your updates. With debug mode enabled, Flask can automatically reload after many code changes.

8. What I Learned Along the Way

Connecting Python to HTML was a learning experience because it introduced me to a different way of building websites.

Before this, I was mainly working with HTML, CSS, and JavaScript. Adding Python and Flask helped me understand how a frontend and backend can work together.

I also learned that organizing files into folders is important. Having a separate place for HTML templates, CSS, JavaScript, and images makes it easier to find files and keep a project organized.

There were moments when I had to troubleshoot errors and figure out why something wasn't connecting correctly. But each step helped me understand more about how Flask works.

Final Thoughts

Learning how to connect Python to HTML is an important step toward building more advanced websites and applications.

You don't have to understand everything right away. Start with a small Flask application, connect one HTML page, and then gradually add more pages and features.

For me, this is another step in my journey toward becoming a full-stack developer.

I'm still learning, building, and figuring things out one step at a time.

Small steps. Big progress.
