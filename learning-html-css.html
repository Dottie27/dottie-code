Learning HTML & CSS

September 26, 2026

I started my coding journey by learning HTML and CSS. At first, my goal was to become a front-end developer and focus on building and designing websites. But with today's world of technology and the way AI is transforming the tech landscape, I became interested in learning more. I decided to expand my skills beyond front-end development and start diving into becoming an full-stack developer.

At first, the amount of code looked a little overwhelming. But as I started practicing, I began to understand what each part of the code was doing.

Starting with HTML

HTML was one of the first things I learned. I learned the HTML is used to create the structure of a webpage, you would compare it to like a structure of an house, that is HTML. It is the heading, paragraphs, images, and links and more.

one of the first examples i learned was how to create a simple heading: 

<h1>Hello, World!</h1>

seeing the code turn into an actual heading on a webpage was really exciting to see.

Then Came CSS

After learning some HTML, I started learning CSS. This is where things started becoming more creative.

CSS allows me to change the appearance of a webapge I can change the colors,fonts spacing and more

for example, I can change the color of a heading with CSS:


            {
            color:#ff4f4f;
            }

This is one of the parts of coding that I really enjoy becuse I can immediately see the changes I'm making to my website.

Building My Own Website

Learning HTML and CSS eventually led me to start building my own website, Dottie Codes.

instead of only following tutorials, i wanted to create something that was my own. I've been experimenting with layouts, colors, fonts, images, navigation menus, and different sections of the website.

There have been moments when something didn't go right, and I've used ChatGPT to help me figure out what was happening. Sometimes it helps me understand what is wrong with my code, but there are also times when I've been able to figure it out on my own without using ChatGPT. Those moments make me feel really good because they show me that I'm starting to understand what I'm learning. Being able to look at my code, find the problem, and fix it myself gives me confidence that I'm actually making progress..

What I'm Learning Now

I'm still learning HTML and CSS and have alot more to learn. I'm currently working on making my website responsive so that it looks good on different screen sizes.

I'm also learning more about how HTML and CSS and Python can eventually work together as I continue working toward becoming a full-stack developer.

What's Next?

I'm going to keep practing HTML and CSS while continuing to build Dottie Codes. Every new section I create gives me another opportunity to learn something new .

This is still the begining of my coding journey, but I'm excited to keep learning, building, and seeing where coding takes me.
